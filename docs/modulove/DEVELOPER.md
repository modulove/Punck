# Punck modulove firmware — developer notes

## Build

`python tools/build.py` (add `--clean` after header changes that the dependency scan misses). Uses the GNU toolchain bundled with STM32CubeIDE 1.19 (found automatically). Output: `build/Punck.elf/.bin/.hex/.map`. Audio code (`src/voices`, `src/dsp`, `src/third_party`) is built with `-O2`, everything else with `-O1` like the CubeIDE Debug configuration.

## Flash (SWD)

J6 on the component board: 1 = 3V3, 2 = GND, 3 = SWDIO, 4 = SWCLK (BOOT0 is not exposed). Tested with a Raspberry Pi Pico 2 running *debugprobe* (CMSIS-DAP): GP2 → SWCLK, GP3 → SWDIO, GND → GND, 3V3 not connected, 100 Ω series resistors. OpenOCD comes from CubeIDE; `tools/openocd/punck_cmsis_dap.cfg` reads memory through the AP0 mem-AP without halting.

```
python tools/swd.py probe                    # check the link
python tools/swd.py backup <dir>             # full 2 MB flash readout (do this first)
python tools/swd.py flash build/Punck.elf    # program + verify (~5 s)
python tools/swd.py restore <dir>/punck_internal_flash_2MB.bin
```
Avoid `swd.py watch` while the module plays live.

## Audio timing and memory

- One sample per SPI2/I2S interrupt at 48 kHz (PLL3, exact). The frame computed in the previous interrupt is written first (`nextOut`); FIFO threshold = one frame. A main-loop watchdog restarts the I2S if the interrupt rate drifts >2 % (upstream's 3-data threshold let the interrupt run up to 68 kHz after overloads: the "wobbly pitch").
- Budget at 400 MHz: 8333 cycles/sample. Hits from all sources are set up one per sample. Measured averages (cycles/sample): reverb ~900–1300, master ~700, trigger/control ~860, string snare (3 strings) ~990, bongo ~670, deep kick ~730.
- Audio code runs from **ITCM** (`STM32H743ZITX_FLASH.ld`: object list + `.itcm_text*` sections; copied in `SystemInit`; 62.8 of 64 KB used). Start-up / config functions of those objects are marked `FLASH_CODE` (`initialisation.h`). Hot Plaits tables live in **DTCM** (`.data.plaits_tables`, generated by `tools/gen_plaits_tables.py`), the snare string delay lines too; the toms string uses AXI SRAM.
- `CPU_480MHZ=1` enables 480 MHz on rev V parts. Off by default: one build did not start standalone in the case (cause not found). Test any clock change with power cycles in the case.
- Faults restart the module and leave a record (`crash`); NaN/inf in a voice, reverb, compressor, clipper or output is dropped, the stage reset and counted (`cpu`).

## Mutable Instruments code

`src/third_party/{plaits,stmlib}` (MIT, see `third_party/LICENSE`). Original files are copied unchanged where possible; adapted files say so in their header. The Punck renders one sample per call, so block-based Plaits code is ported as: per-block setup only when a parameter changes, per-sample body unchanged. `voices/PlaitsSynth` runs the control part of `plaits::Voice` (decay envelope, LPG) every 12 samples like Plaits; `voices/KarplusString` is the Plaits string engine with its limiter.

## Tests

- **Host renderer** `tools/hostsim` (MSYS2 MinGW g++): compiles the real voice code against stub headers. `sh tools/hostsim/build_hostsim.sh <outdir>` renders reference WAVs and level stats; extra modes: `render.exe <dir> strings | synths | drive | snaresustain | longrun <hours>`. Compare against a reference folder with `cmp` for bit-identical refactors.
- **Stress test** `tools/stress_test.py`: every engine combination under 7 MIDI scenarios (incl. floods) with random parameters; flags underruns, CPU > 95 %, restarts, faults, audio-rate drift, NaN, runaway levels; SWD health per combination. `--passes 1`, `--only snare=6,toms=3`, `--replay RUN:ID,…`, `--restore RUN` (verifies and saves). Loud — monitors down. Always confirm the *saved* state afterwards (`cfg`, or a reboot).
- `tools/usb_torture.py`, `tools/level_test.py` (interface calibration), `tools/wobble_check.py`, `tools/longrun_monitor.py`.

## Upstream issues fixed here (not yet reported upstream)

| Area | Issue | Fix |
|---|---|---|
| I2S | FIFO threshold 3 data vs 2 writes per interrupt: interrupt rate up to 68 kHz after overloads, pitch wobble | 1-frame threshold, frame first, rate watchdog |
| USB | ZLP started with PKTCNT 0; EP0 OUT not re-armed for SETUP; one shared `transmitting` flag for all IN endpoints (console hangs) | PKTCNT 1, abort/re-arm EP0, per-endpoint flags |
| Settings | Flash error flags cleared via read-only SR2 (one error disables saving until reset); `FlashProgram` reports success when nothing was written; SER/SNB left set after erase; MIDI channel did not fit the config array | CCR2, return codes, verify + retry, larger config |
| Voices | Classic snare per-sample decay could exceed 1 (level → inf); claps band pass retuned per hit without limits (blow-ups) | caps and limits |
| Console | Non-volatile busy flag: lost output lines | volatile, time-limited wait |
